[ Case study ][ Brand Experience / Creative Production ][ 02 / 2026 ]

Aletheia /dirección creativapara un EP.

Construyendo un universo antes de lanzar una obra.

  • [ Dirección de arte ]
  • [ Narrativa transmedia ]
  • [ Producción audiovisual ]
[ Cliente ]
Aletheia, banda de rock
[ Servicios ]
Dirección de arte, narrativa transmedia, producción audiovisual
[ Rol ]
Dirección creativa integral
[ Año ]
2026

Algunas historias no comienzan cuando se publica una canción, sino mucho antes. Comienzan en las preguntas, en el silencio y en la intención de construir algo que trascienda un lanzamiento. Ese fue el punto de partida de Aletheia.

Desde REACH desarrollamos una dirección creativa integral para acompañar el lanzamiento de su EP. Más que diseñar una campaña, nuestro objetivo fue crear un universo narrativo capaz de darle identidad al proyecto y permitir que cada pieza de comunicación respondiera a una misma visión.

[ Dirección artística ]

Cada decisión visual nació de un concepto común. La luz, el fuego, el viento, el agua, el paso del tiempo y la transformación se convirtieron en elementos que atraviesan toda la narrativa, no como recursos estéticos aislados, sino como símbolos que dialogan entre sí y le dan coherencia a la experiencia.

La identidad fue concebida desde un lenguaje cinematográfico, donde el ritmo, la composición y el espacio tienen la misma importancia que las palabras. La intención nunca fue explicar el mensaje, sino generar el contexto para que pudiera ser descubierto.

[ Narrativa y lanzamiento ]

El lanzamiento fue pensado como una historia contada en distintos capítulos. Cada teaser, cada publicación y cada decisión audiovisual responde a un recorrido emocional diseñado para despertar curiosidad, sostener la expectativa y preparar al espectador para la llegada del EP.

El relato se construyó de manera progresiva, utilizando el misterio como herramienta narrativa y permitiendo que cada nueva pieza ampliara el universo en lugar de repetir información.

[ Una identidad con propósito ]

Más allá de la producción audiovisual, el trabajo consistió en definir una identidad capaz de mantenerse consistente en todos los puntos de contacto de la banda. La narrativa, la estética, el sonido y la comunicación fueron desarrollados bajo una misma dirección creativa para que el proyecto pudiera expresarse con claridad y autenticidad.

El resultado es un lanzamiento que entiende la música como parte de una experiencia más amplia, donde cada imagen, cada silencio y cada decisión visual contribuyen a construir un mismo relato. Porque cuando todas las piezas hablan el mismo lenguaje, una campaña deja de ser una sucesión de publicaciones y se convierte en un universo que el público puede habitar.

Aletheia define el viaje más importante de nuestras vidas
